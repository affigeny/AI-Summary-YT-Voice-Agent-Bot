> Telegram-бот: ссылка YouTube / ID видео / аудио / голосовое → транскрипт → переработка по шаблону через ИИ. Продвинутый обход блокировок YouTube.

## 🚀 Возможности

| Функция | Описание |
|---------|----------|
| 📹 **YouTube / Shorts / ID** | Ссылка, shorts или просто 11-символьный ID видео |
| 🛡 **Обход блокировок** | Цепочка из 9 методов (см. ниже), прокси и куки из env |
| 🎙 **Голосовые / аудио / видео** | Распознавание через Google Speech (бесплатно, без загрузки моделей) |
| 🤖 **LLM-переработка** | Саммари · Минто · экшен-план · конспект · свои шаблоны |
| ⌨️ **Постоянное меню кнопок** | Навигация всегда внизу экрана — листать вверх не нужно |
| ⚙️ **Формат вывода на выбор** | Результат в чат · `.md` файлом · оба варианта |
| 📝 **Шаблоны видны и правятся** | Полный текст промпта, редактирование и создание своих кнопками |
| 💾 **История транскриптов** | Всё сохраняется в БД, `/history` — обработать заново |
| 💬 **Интерактивный чат** | Диалог с ИИ по содержимому после обработки |
| ⬇️ **Скачивание медиа** | Видео/аудио в любом качестве кнопками |
| 🩺 **Health-check** | Обход засыпания на Render Free |

## ⌨️ Навигация

Постоянная клавиатура (`is_persistent`) закреплена внизу чата — доступна всегда,
без прокрутки истории:

| Кнопка | Действие |
|--------|----------|
| ⚙️ **Меню обработки** | Вернуть меню шаблонов в любой момент — не нужно листать вверх |
| 📝 **Шаблоны** | Список шаблонов → просмотр текста промпта → изменить / удалить / создать свой |
| 🕙 **История** | Сохранённые транскрипты с названиями — обработать заново |
| 🧠 **Нейросеть** | Выбор ИИ, авто-перебор, свои ключи и модели, тест |
| ⚙️ **Формат вывода** | Куда отдавать результат: в чат / `.md` файлом / оба |
| 🔓 **Обход YouTube** | Выбор и тест метода обхода блокировок |
| ℹ️ **Помощь** | Краткая справка |

### После обработки меню остаётся

Результат никогда не оставляет в тупике — под ним всегда кнопки:

| Кнопка | Когда полезна |
|--------|---------------|
| ♻️ **Ещё раз** | Ответ ИИ не понравился или сорвался — повторить тем же шаблоном |
| 🔄 **Другой шаблон** | Передумали: вернуться к выбору обработки |
| 💬 **Обсуждаем: …** | Переключить контекст вопросов: результат ИИ ↔ исходный транскрипт |
| ⚙️ **Формат вывода** | Сменить формат и сразу «Повторить в этом формате» |
| 🧠 **Нейросеть** | Сменить провайдера, если этот отвечает плохо |
| 📄 **Транскрипт** | Забрать исходный текст файлом |

При ошибке ИИ бот показывает **причину человеческим языком** (лимит токенов,
неверный ключ, превышена квота, таймаут) и предлагает «♻️ Повторить» либо
«🔄 Выбрать другой шаблон». Скачивание файлов при bot-check тоже объясняется
по-человечески и возвращает меню, а не оставляет в тупике.

## 🕙 История транскриптов

Кнопки списка собираются из иконки источника, названия, объёма и даты:

```
📺 Как работают трансформеры — л… · 12.4к · сегодня 18:30
🎤 Голосовое сообщение · 150 · вчера 22:10
🎵 podcast_episode_42 · 30к · 19.08 09:05
```

Название YouTube-видео берётся через публичный **oEmbed** — он работает без
куки и авторизации, поэтому заголовки появляются даже когда `yt-dlp` упирается
в bot-check. У записей, сохранённых раньше без названия, заголовок
**дописывается задним числом** при первом открытии истории.

Расширения файлов (`.mp3`, `.mp4`, …) в подписях убираются, длинные названия
усекаются, объём показывается как `12.4к`, дата — как «сегодня / вчера / 19.08».

## 💬 Обсуждение: что берётся в контекст

Частая путаница «бот не понимает, что обсуждать» решена явным переключателем:

| Режим | Что уходит в LLM |
|-------|------------------|
| **результат** (по умолчанию после обработки) | Ответ ИИ + история диалога |
| **транскрипт** | Исходный текст видео/аудио + история диалога |

Диалог сбрасывается при переключении, чтобы контексты не смешивались.
Кнопка 🗑 **Сбросить диалог** очищает историю, сохраняя транскрипт и результат.

## ⚙️ Формат вывода результата

Выбирается кнопкой и запоминается для пользователя в БД:

| Режим | Что происходит |
|-------|----------------|
| 💬 **Только в чат** | Текст сообщениями, разбивка по 4000 символов |
| 📄 **Только .md файлом** | Готовая заметка для Obsidian (см. ниже) |
| 🔀 **В чат + .md** | Оба варианта одновременно |

### Как выглядит .md

Имя файла собирается из названия видео, шаблона и даты:

```
Как работают трансформеры лекция №3 — Краткое саммари — 2026-08-21.md
```

Внутри — YAML-frontmatter, который Obsidian показывает как свойства заметки:

```markdown
---
title: "Как работают трансформеры: лекция №3"
date: 2026-08-21 23:12
source: youtube
url: https://youtu.be/abc123
processing: "📝 Краткое саммари"
tags: [транскрипт, yt-bot-sum]
---

# Как работают трансформеры: лекция №3

🎬 [Смотреть на YouTube](https://youtu.be/abc123)

> Обработка: **📝 Краткое саммари** · 21.08.2026 23:12

---

…результат ИИ…
```

Кириллица в имени сохраняется, запрещённые в файловых системах символы
(`\ / : * ? " < > |`) вычищаются.

## 🧠 Выбор нейросети

Кнопка «🧠 Нейросеть» или `/ai` — меню устроено как выбор обхода YouTube.

| Провайдер | Модель по умолчанию | Ключ из env |
|-----------|--------------------|-------------|
| 🔷 Google Gemini | `gemini-3.6-flash` | `GEMINI_API_KEY` |
| ⚡ Groq | `llama-3.3-70b-versatile` | `GROQ_API_KEY` |
| 🧠 Cerebras | `llama-3.3-70b` | `CEREBRAS_API_KEY` |
| 🌐 OpenRouter | `…llama-3.3-70b-instruct:free` | `OPENROUTER_API_KEY` |
| 🌬 Mistral | `mistral-small-latest` | `MISTRAL_API_KEY` |
| 🤝 Together AI | `…Llama-3.3-70B-Instruct-Turbo-Free` | `TOGETHER_API_KEY` |
| 🐙 GitHub Models | `gpt-4o-mini` | `GITHUB_MODELS_TOKEN` |
| 🔧 Свой API | задаётся вручную | — |

Кнопки меню:

| Кнопка | Действие |
|--------|----------|
| 🤖 **Авто** | Берёт первый доступный провайдер из цепочки |
| 🔁 **Авто-перебор при ошибке** | При отказе провайдера запрос уходит следующему; в ответе помечается, кто сработал |
| 🧪 **Тест** | Реальный запрос к провайдеру (или ко всей цепочке) с отчётом по каждому |
| 📥 **Модели** | `GET /models` у провайдера; бесплатные и компактные показываются первыми, выбор кнопкой |
| 🔗 **URL** / 🔑 **Ключ** / 🧩 **Модель** | Свои значения для любого OpenAI-совместимого эндпоинта, включая локальный Ollama |
| ♻️ **Сбросить** | Возврат к авто-выбору и ключам из переменных окружения |

Приоритет ключей: **личный ключ пользователя → переменная окружения
провайдера → общий `AI_API_KEY`**. 🔑 у кнопки означает, что для этого
провайдера ключа пока нет.

Ключи не печатаются в чат: показывается только усечённый вид (`sk-a…6789`),
а сообщение с введённым ключом бот удаляет сразу после сохранения.

## 📝 Шаблоны: смотреть, менять, создавать

Кнопка «📝 Шаблоны» открывает список. Нажатие на шаблон показывает **полный
текст промпта** и кнопки:

- ✏️ **Изменить текст** — бот ждёт следующее сообщение с новым промптом;
- 🗑 **Удалить** — только для своих шаблонов;
- ➕ **Создать свой шаблон** — формат `Название | текст промпта`, ID выдаётся автоматически.

Стандартные шаблоны удалить нельзя, но можно переопределить их текст.
Отмена ввода в любой момент — `/cancel`.

| Компонент | Технология |

## 🛡 Цепочка обхода блокировок YouTube

Движок `yt_transcript.py` пробует методы по порядку до первого успеха:

| # | Метод | Как работает |
|---|-------|--------------|
| 1 | ⚡ InnerTube API | `youtube-transcript-api` — быстрый прямой API-вызов |
| 2 | 🛰️ kome.ai API | Внешний сервис тянет транскрипт со своих серверов — работает даже с датацентровых IP, которые YouTube блокирует |
| 3 | 🤖 yt-dlp Android VR | `player_client=android_vr` — без PO-токена, стабилен |
| 4 | 💧 Piped-зеркала | Публичные зеркала, проксирующие YouTube |
| 5 | 🔧 yt-dlp (web) | Стандартный клиент с браузерным User-Agent |
| 6 | 📺 yt-dlp TV-клиент | `player_client=tv` — не требует PO-токен |
| 7 | 📱 yt-dlp mWeb | `player_client=mweb` — мобильный веб-клиент |
| 8 | 🪞 Invidious-зеркала | Публичные зеркала (список проверяется, env `INVIDIOUS_INSTANCES`) |
| 9 | 🍪 yt-dlp + куки | Куки аккаунта (env `YT_COOKIES` или файл) |

Если субтитров нет или все методы заблокированы — бот скачивает аудио
(клиенты android_vr → tv → mweb → web → куки) и распознаёт речь через
Google Speech Recognition.

`/bypass` — закрепить конкретный метод или прогнать «🧪 Тест всех методов»:
отчёт по субтитрам **и** по скачиванию аудио (на датацентровых IP субтитры
часто блокируются, а аудио качается — тогда бот работает через распознавание).

## ⚙️ Переменные окружения

| Переменная | Назначение | По умолчанию |
|------------|-----------|--------------|
| `TELEGRAM_BOT_TOKEN` | Токен бота | — |
| `AI_API_KEY` / `AI_API_URL` / `AI_MODEL` | LLM по умолчанию (Google Gemini) | generativelanguage... /v1beta/openai + gemini-3.6-flash |
| `GEMINI_API_KEY`, `GROQ_API_KEY`, `CEREBRAS_API_KEY`, `OPENROUTER_API_KEY`, `MISTRAL_API_KEY`, `TOGETHER_API_KEY`, `GITHUB_MODELS_TOKEN` | Ключи провайдеров для меню «🧠 Нейросеть» и авто-перебора | — |
| `STT_LANGUAGE` | Язык распознавания речи | `ru-RU` |
| `STT_CHUNK_SECONDS` | Длина чанка аудио для Google Speech (<60) | 50 |
| `STT_TIMEOUT` | Таймаут распознавания, сек | 600 |
| `MAX_AUDIO_SECONDS` | Максимум обрабатываемого аудио, сек | 1800 |
| `YT_COOKIES` | **Содержимое** cookies.txt в env (для Render) | — |
| `YT_COOKIES_FILE` | Путь к файлу куки | — |
| `YT_PROXY` | Прокси для всех запросов к YouTube | — |
| `LLM_MAX_CHARS` | Лимит контекста для LLM (голова+хвост) | 24000 |
| `HISTORY_MAX_MESSAGES` | Сколько последних сообщений диалога уходит в LLM | 12 |
| `HISTORY_MSG_MAX_CHARS` | Обрезка одного сообщения диалога | 4000 |
| `LLM_TIMEOUT` | Таймаут ответа модели, сек | 240 |
| `INVIDIOUS_INSTANCES` / `PIPED_INSTANCES` | Свои зеркала (через запятую) | публичные |
| `DB_PATH` | Путь к SQLite | bot_database.db |

## 📱 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Справка и начало работы (включает постоянное меню кнопок) |
| `/templates` | Шаблоны: смотреть текст, менять, создавать свои |
| `/history` | Сохранённые транскрипты — обработать заново |
| `/ai` | Выбор нейросети: провайдер, авто-перебор, свои ключи, тест, модели |
| `/bypass` | Выбор/тест метода обхода YouTube |
| `/add_template ID \| Название \| Промпт` | Свой шаблон командой |
| `/del_template ID` | Удалить свой шаблон |
| `/cancel` | Отменить ввод текста шаблона |
| `/stats` | Статистика |

Основная навигация — **постоянными кнопками внизу чата**, команды нужны только
для тонких операций. После транскрипта появляются инлайн-кнопки: шаблоны (2 в ряд)
· 📄 транскрипт файлом · 🕙 история · ⚙️ формат вывода · 📝 шаблоны · ⬇️ скачать медиа.
